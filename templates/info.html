How to read the evidence panel

Heatmap

Shows regions that contribute to the selected model output, not a guaranteed tumor mask.

Boundary estimate

An attention-guided contour for visual inspection. It must not be treated as a segmentation ground truth.

Confidence

A model score for the selected class. It is not a diagnosis or a calibrated clinical probability.

Model Training Pipeline

Deep Learning Architecture & Training

Overview of the training pipeline used to build the NeuroScan AI classification models.

1

Data Preprocessing

  • Resized all MRI images to 224x224 pixels
  • Normalized pixel values to 0-1 range
  • Applied data augmentation (rotation, flip, zoom)
  • Pickled preprocessed data for reuse
2

Model Architectures

  • VGG16: Transfer learning with ImageNet weights
  • EfficientNetB0: Efficient architecture, high accuracy
  • Custom Deep CNN: 6-layer CNN with BatchNorm
  • ANN: Dense layers for baseline comparison
3

Training Config

  • Optimizer: Adam (lr=0.001)
  • Loss: Categorical Crossentropy
  • Batch size: 32
  • Callbacks: EarlyStopping, ReduceLROnPlateau, TensorBoard
4

Ensemble Learning

  • EfficientNet: 50% weight
  • VGG16: 35% weight
  • Custom CNN: 15% weight
  • Achieved 99%+ accuracy

3D Volumetric Pipeline

In addition to the 2D pipeline, a 3D volumetric pipeline was trained using Conv3D architectures on the RSNA-MICCAI dataset for MGMT biomarker prediction. The 3D models process complete brain volumes (64 slices) instead of single 2D slices.

Mask R-CNN Segmentation Model

A separate Mask R-CNN model was trained for instance segmentation of brain tumors. This model detects tumors and generates precise pixel-level masks with bounding boxes.

85% Confidence Threshold

Custom Training

Trained on annotated brain tumor dataset with custom Mask R-CNN configuration.

The Mask R-CNN segmentation model was trained in Google Colab using TensorFlow 1.x. The live web app uses AI Attention Analysis (Grad-CAM + Saliency) for real-time tumor localization, which is compatible with TensorFlow 2.x.
